# risecode 0.24.2 — GUI rendering

[All versions](README.md) · [Changelog](../../CHANGELOG.md) · [Project home](../../README.md)

Reduce repeated GUI work while preserving the current appearance. Bitmap text uses cached
glyph runs; compatible commands share batches without changing overlapping paint order.
Prepared Unicode fallback glyphs and repeated layout are cached, hidden collapsed controls
skip measurement, and blur filtering follows the full sampling footprint of requested regions.

Font interpolation, blur/glow/shadow settings and live animations remain. The changes apply
with Performance mode Off and require no profile migration. Minecraft 26.2 / Java 25 remain
the targets. See [the investigation](../gui-rendering.md) for measurements and validation
boundaries.

Validation: project checks, four native renderer configurations and 44 exact pixel
comparisons pass. The final shared-load follow-up reduced Search render-thread CPU from
7.81 to 2.54 ms per frame, draw calls from about 927 to 18, and allocation from 1.84 to
0.31 MB per frame. The earlier three-pair candidate comparison reduced Search frame time
from 7.82 to 3.21 ms. These runs are described separately in the investigation.

The within-10% closed/open FPS goal remains outstanding. A concurrent user game affected
the final timing controls, so its raw near-target ratio is not accepted as proof.

Installed into the authorized Fabric 26.2 profile with a verified backup and checksum;
other mods and saved settings are preserved. Restart Minecraft to load the update.
