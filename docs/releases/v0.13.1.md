# risecode 0.13.1

Removes the embedded AI Agent feature for Minecraft 26.2 / Java 25.

- Removed the Agent page, model providers, chat/history loading, tool execution,
  background services and Agent task/renderer/inventory hooks.
- Removed Agent-only tests, fixtures, benchmarks and current documentation.
- Kept the regular Baritone module and `.b` commands, Styles, HUD, profiles,
  appearance controls and shared text editing/settings serialization.
- Saved AI/Agent tab selections now open Search. F12 can be bound normally.
- Existing configurations, including old Agent records, remain on disk.

Restart Minecraft to load the updated JAR.
