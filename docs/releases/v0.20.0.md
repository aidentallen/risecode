# risecode 0.20.0

Minecraft 26.2 · Java 25 · Fabric Loader 0.19.5 · Fabric API 0.161.0+26.2.

## Container screens

- Restore inventory panels, native slots and the player preview when using custom backdrops.
- Add Minecraft and risecode container styles, globally and per screen through the gear.
- Theme inventory, creative/storage/workstation containers and recipe-book surfaces and controls.
- Preserve native geometry, item handling, recipe behavior and readable item counts.
- Suspend container cleanup while its appearance editor is open, preserving the carried item.

## Background layers

- Add Background: None for the native world/menu backdrop.
- Render particles independently from backgrounds and blur passes.
- Give page particles their own inheritance switch, preserving existing local values.
- Keep HUD particles independent of image opacity and panel background opacity.

## Client settings popup

The bottom-left player/settings button opens Profiles, Friends, Client Sounds,
Command Suggestions, Discord Activity, Menu Keybind and GUI Scale. Profiles retains
all client/appearance profile actions; Friends and Profiles leave Utilities.

Client sounds have a master toggle and their existing preset/import/volume/pitch
panel. Suggestions complete local client command names, aliases and relevant
arguments, including optional Baritone. Slash-command completion stays native.
Discord activity is opt-in with a public application-ID setup field and local IPC
status. It publishes only Minecraft and risecode, and clears activity on disable.
Menu key capture changes the existing key mapping, including focused-search closing.
GUI scale uses the existing appearance value, shown as a percentage.

## Compatibility and validation

No existing gameplay, map, friend or cosmetic data is relocated. Theme/page settings
migrate explicitly, and module appearance inheritance remains supported. New client
preferences stay independent of gameplay and appearance profiles.

Validation includes preference migration, quoted/cursor-aware command completions,
local framed Discord IPC, real native container rendering, inventory item input,
particle pixel comparisons and popup input across renderer stacks. Live Discord
account presence additionally requires a configured application ID.

## Outline and appearance polish

- Add **See-through Outline** to Block Overlay, off by default. It covers every edge,
  corner segments and inside-block pop animation without changing fill depth behavior.
- Increase line and outline thickness limits to 32 pixels.
- Preserve Block Overlay fill, custom width, translucent colors, corner gaps and
  see-through edges with Iris shaders, including packs that disable selection outlines.
  Composite overlays after shader processing and retain scene depth for normal edges.
- Limit per-module Appearance to actual output capabilities; nonvisual modules omit it.
  GUI cards keep global styling. Global mode hides overrides, and inactive saved fields
  remain recoverable through profile round trips.
- Match Appearance sections to module cards, including headers, shape, spacing,
  hover/press feedback, animated expansion and persistent collapsed states.
- Animate native menu buttons around their own centers, leaving panels and labels
  stationary. ClickGUI keeps its independent window animation. Pointer coordinates
  follow the button pose, including supported Sodium buttons.
- Expand extensible numeric limits by four times, with 60-second animation durations,
  128 blur radius, 1,536 background particles, 4x font scale and 3x interface scale.
  Normalized values, percentages, colors, coordinates and native constraints stay bounded.
- Reserve most slider travel for familiar values while exposing the full extension;
  preserve numeric typing, keyboard precision, validation and saved defaults.
- Update consumer caps, shader fields, blur pyramid, particle pools, cosmetic budgets,
  chat history, tab rows and block-index snapshots to support the new limits.
