# risecode 0.16.0 — Shared appearance, cave maps and polish

[All versions](README.md) · [Changelog](../../CHANGELOG.md) · [Project home](../../README.md)

Minecraft 26.2 / Java 25. MIT license; existing module profiles, explored surface
terrain, waypoints and HUD placement remain compatible.

- Shared backdrops for risecode, native menus, supported mod menus and containers.
  Browse lake, scenic, space, abstract, gradient, solid and imported local PNGs;
  adjust darkness, tint, blur and opacity. Original bundled additions retain credits.
- Global and per-window entrance controls, profile-persistent module Pop In,
  Reduced Motion, immediate spring button feedback, soft pop/blob/vanilla/muted
  sounds and local OGG import with preview, volume and pitch.
- Inline expandable sidebar utilities, independent Width / Height, resize handle,
  Reset Layout and a pause-menu risecode GUI button that returns to the pause menu.
  Resources uses compact browsing controls and a Tools menu.
- Shared styled text for components and legacy formatting, including custom-font
  chat measurement, wrapping and clickable regions. BetterChat, BetterTab and
  Nametags use the appearance palette and stable entrance identities. Native chat
  signing/deletion metadata, tab content and equipment remain available.
- Zoom enablement arms Hold / Toggle activation; wheel changes remain temporary.
  Interruptions release active zoom. FreeLook moves to Render without an ID change.
  Enchanted outlines cover regular and special item models, including held and
  charging tridents, retaining the existing first-person / optional world scope.
  Actual enchantment metadata keeps outlines active when native glint is suppressed.
- One detailed terrain renderer for minimap and world map: top-face detail,
  biome tint, neighboring-height contours, shoreline/water depth and coarse coverage
  while detail loads. Fullscreen and persistent movable/resizable panel modes.
- Auto / Surface / Cave, roof/sky filtering, altitude hysteresis and manual layers.
  Cave tiles show floors and fluids, isolate dimension/layer/altitude, retain
  recoloring data and read existing surface files without clearing exploration.
- Bounded capture, workers and uploads; CPU residency capped at 64 MiB and GPU at
  128 MiB, with stale world/resource results rejected. Minimap adds Square / Circle
  and map backgrounds can inherit Appearance or choose independent styling.
- Death history records independently of recording and overlay switches, buffers
  loading-time deaths, retains reached points, tracks the latest per dimension
  and uses paged history with hide-reached and bulk-clear controls.

See [user guide](../usage.md) for controls and data locations.
Restart Minecraft after replacing the JAR; a running game is not stopped by the
installation workflow. Renderer verification and installation receipts are kept
under the local build/verification/0.16.0 directory, outside source control.

Verification: 887 core assertions. Native feature and silhouette suites passed
72 assertions on each of vanilla OpenGL, the installed Sodium/Iris OpenGL stack,
and installed Sodium Vulkan. The overlay/gameplay suite passed 182 assertions
on each path; Resources passed 36 on vanilla and 38 on each installed renderer.
Checks include real local font/image/sound assets, signed-message metadata,
120-player tab lists, equipped nametags, scaled input, small-height navigation,
resize handles, cave floors/stacked layers, migration and byte/work limits.
Screenshots of video settings, pause access, Resources, overlays, map modes and
waypoint editing were inspected. Tests use disposable client worlds and preserve
the installed instance until the verified JAR replacement.
