# risecode 0.8.0 — Render, camera, HUD, and menu polish

Archived release restored from retained artifacts. Original publication dates and Git history were not retained.

## Changes

- Added StorageESP, PlayerESP, BlockESP, Crosshair scaling, independent hand ViewModel transforms, and Hold-C Zoom.
- Added selected-tab colors, HUD borders, collapsible color pickers, and configurable dropped-item rotation/spin.
- Added vector sidebar icons, text/HUD caching, and independent Start/Multiplayer/Options theming.
- Recovered the original installed JAR from its backup and the preserved source-0.8.0 snapshot. Later overwritten build-folder copies are deliberately excluded.

## Requirements

Minecraft 26.2, Java 25, Fabric Loader, and Fabric API. Install the mod JAR; sources are separate.

## Provenance

Notes were reconstructed from the retained binary/source artifacts and [POLISH.md](https://github.com/aidentallen/risecode/blob/main/POLISH.md). The documentation on main also contains later updates.

Historical tags contain recovered source snapshots, not reconstructed development commits. Except for the full 0.8.0 snapshot, older source JARs retain production source/resources but not the complete build/test workspace.

Original code is MIT licensed. Third-party files retain their licenses; `risecode-licenses.zip` contains the license texts and attribution. Baritone remains an optional [upstream download](https://github.com/cabaletta/baritone/releases/tag/v1.19.0).
