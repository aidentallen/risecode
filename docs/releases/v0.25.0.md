# risecode 0.25.0 — Rendering, typography and world resolution

[All versions](README.md) · [Changelog](../../CHANGELOG.md) · [Project home](../../README.md)

Chest placement owns cached BBE geometry only after the stamped hidden mesh is uploaded.
Motion starts at that handoff, with a one-second deadline for unsuccessful transfers.
Ownership advances before block-entity extraction so the dispatcher and terrain agree
about the same frame.
Single/double/trapped chests use native renderers and lid state; double chest halves share
one pivot and clock. Completion restores static mesh ownership, and removal cancels the
group. Fluids, unsupported multipart blocks and shader-emissive exclusions remain.

PlayerESP rejects shadow passes before custom submissions and uses the extracted model
state origin, matching vanilla xOld/yOld/zOld interpolation. A single immutable frame carries
geometry and submissions, silhouette style batches preserve insertion order, and masks clear
once per frame and copy current world depth at their first draw. Native models, armor,
friend colors and VisibleOnly remain in the silhouette path.

BlockOverlay adds Custom (default), Rainbow Cycle and Spatial Rainbow. Cycle shares a hue;
Spatial Rainbow samples absolute world X+Y+Z. Speed and spacing do not change fill, width,
corner/full geometry, opacity, depth mode or placement following. This uses original HSV
math, with the installed AstraLex selector behavior as a visual reference.

Google Sans Regular/Medium retain their original bytes and OFL notices. Qraftys' original
2.1 bitmap and namespaced definition are bundled with the redistribution permission
confirmed for this release. The PNG SHA-256 is
`b3aa3de3f4a8ecc6f1b71c05f03765b5202178b915df478869b0d74717b7e0df`.
Explicit local overrides and the selected font remain supported.

Appearance → Typography → Font Boldness ranges from 0–100, default 0. It adds up to 0.75
logical pixels of stroke to body, shadow, glow and Unicode fallback, preserving advances
and wrapping. Extracted draws capture stroke; slider edits do not rebuild atlases. The zero
path retains the previous atlas, sampling and geometry. Appearance disclosure headers
accept both mouse buttons; footer detail rows open and expand their canonical client page.
Left-click quick toggles and control-specific right-click actions remain.

Performance is a main sidebar tab; the footer shortcut opens the same settings. World
Resolution (25–100%, 1% steps, default 100), Upscaler (Bilinear/FSR1, default FSR1) and
FSR1 Sharpness (0–1, default 0.2) are stored additively under performance.rendering.
Reduction presets never alter these preferences.

World, hand, particles, entities and world masks render at the selected extent. Overlays
compose there before upscaling; HUD, menus and GUI blur then render at the native output
extent. Window/input/GUI scale and projection FOV stay native. The 100% path allocates no
scaling target and submits no scaling pass. The sky adapter resolves the current frame's
target, avoiding a stale target after resize or reload.

AMD reference EASU and RCAS headers are pinned to
`a21ffb8f6c13233ba336352bdff293894c706575` and included unmodified with the MIT notice.
The wrappers use Minecraft's GPU pipelines on OpenGL, Sodium/Iris and native Vulkan.
Sharpness maps 0 to no RCAS sharpening and 1 to maximum reference strength. This release
uses spatial scaling only. Recognized competing scaling mods retain ownership; unsupported
FSR1 falls back to Bilinear, and an unsupported scaling path returns to native. Requested
preferences remain saved, with actual extents and the reason shown on Performance.

Validation: the complete project checks pass, including 128 release-specific assertions.
Every native run uses the packaged release JAR with SHA-256
`1699f429ac00d37e7866870975df94e9ab1a13e062b37e65417e9a6c4211b363`.

Both Google Sans and Qraftys at zero boldness match 0.24.2 pixel for pixel in the fixed
multi-scale Unicode font probes: zero changed pixels for both fonts. Fresh native
runs have no external font pack. Tests exercise right-click disclosures and popup entrance
transforms, 100/75/50/25% scaling, fallback preference preservation, pause/resize/fullscreen,
resource/shader reload, moving/overlapping player silhouettes with armor/friends/VisibleOnly,
explicit shadow-pass exclusion, single/double/trapped chest orientations and lid motion,
BBE static-cache handoffs, removal, timeout, and stable/released scale targets.

CPU, GPU, allocation and wall-frame costs are recorded separately per scene, with extents,
in the private `.tooling/release025/verification.json` and per-run `025-costs.json` files.
These shared-host samples do not establish an FPS improvement. AstraLex V93 reports no DH
shader; Complementary is also tested with the installed DH stack. Native fixtures do not
establish live-multiplayer, long-session or arbitrary-shader performance. The existing
owner-only empty teardown adapter is test-only and absent from the release JAR.

files or configuration. Minecraft was left running; a restart is required. The private
installation receipt is `.tooling/release025/install-receipt.json`.
