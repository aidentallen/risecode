# 0.11.2 — AI streaming and retention performance

Historical release: the Agent feature and its guides were removed in [0.13.1](v0.13.1.md).

Streaming now reuses unchanged Markdown paragraphs and wraps text with the same
glyph advances, kerning and rounding used by the native font renderer. It avoids
building a font layout for every successive prefix. Unchanged chat snapshots are
also reused between frames.

Leaving or closing the AI panel releases its message layout cache while retaining
the conversation and composer draft. Clear/restoration resets scroll positions;
display clipping preserves Unicode codepoint boundaries.

The disposable native benchmark measures repeated frame intervals for idle,
module/AI pages, streaming, tool bursts and long conversation scrolling. It also
checks cleared-message reachability and worker cleanup. The deterministic endpoint
is an HTTP/SSE fixture, not a live language model. Measurement evidence and limits
are described in AI performance validation.

Minecraft 26.2 / Java 25, Styles, ordinary profiles and opt-in conversation storage
remain compatible. This patch adds no gameplay tasks or automatic FPS optimizer.
