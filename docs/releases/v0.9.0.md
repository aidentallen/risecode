# risecode 0.9.0 — Ambience, Appearance, and rendering upgrade

Archived release restored from retained artifacts. Original publication dates and Git history were not retained.

## Changes

- Added procedural Ambience skies and animated water with native/Sodium adapters and Iris shader-pack handoff.
- Added optional official Baritone controls, command forwarding/completion, missing-dependency status, and safe task lifecycle.
- Added focused typed settings, branding/PNG logos, Appearance presets with Undo, Watermark/ArrayList HUD modules, and independent animation channels.
- Expanded native-menu theming, loading controls, title-screen interface access, and uncapped themed menus.
- Added shader-sampled gradients, rendering/layout caches, and blur/resource reuse. Historical performance evidence is documented in the upgrade guide.

## Requirements

Minecraft 26.2, Java 25, Fabric Loader, and Fabric API. Install the mod JAR; sources are separate.

## Provenance

Notes were reconstructed from the retained binary/source artifacts and [UPGRADE.md](https://github.com/aidentallen/risecode/blob/main/UPGRADE.md). The documentation on main also contains later updates.

Historical tags contain recovered source snapshots, not reconstructed development commits. Except for the full 0.8.0 snapshot, older source JARs retain production source/resources but not the complete build/test workspace.

Original code is MIT licensed. Third-party files retain their licenses; `risecode-licenses.zip` contains the license texts and attribution. Baritone remains an optional [upstream download](https://github.com/cabaletta/baritone/releases/tag/v1.19.0).
