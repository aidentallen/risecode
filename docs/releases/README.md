## About this history

Versions 0.1.0–0.9.2 were recovered from retained binary/source artifacts. Their
notes retain hashes and provenance; recovery does not recreate original
publication dates or development commits. Old source-delivery notes are linked
to an immutable Git commit so their evidence survives cleanup of the current tree.

Later versions retain their feature, migration, and verification notes. Historical
features describe their own release: Agent was removed in 0.13.1, and Resources
replaced the Styles browser in 0.14.0.

This index documents version history; it does not imply that every version has a
published GitHub Release or a downloadable binary. The [release manifest](manifest.json)
lists all 42 versions and preserves the recorded early artifact checksums.
