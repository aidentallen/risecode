# risecode 0.1.0 — Earliest retained Fabric client

[All versions](README.md) · [Changelog](../../CHANGELOG.md) · [Project home](../../README.md)

Archived release restored from retained artifacts. Original publication dates and Git history were not retained.

## Changes

- Java 25 / Minecraft 26.2 client foundation with settings, synchronous EventBus, module lifecycle, and retargetable animations.
- Retained build includes the animated category/card ClickGUI, search, watermark/ArrayList HUD, and FullBright module.
- This is the earliest surviving binary/source pair; the original development history predates Git and cannot be reconstructed fully.

## Requirements

Minecraft 26.2, Java 25, Fabric Loader, and Fabric API. Install the mod JAR; sources are separate.

## Provenance

Notes were reconstructed from the retained binary/source artifacts and [PHASE3.md](https://github.com/aidentallen/risecode/blob/44cc1f286ac601a59e65061626fce306be41645e/PHASE3.md), [PHASE4.md](https://github.com/aidentallen/risecode/blob/44cc1f286ac601a59e65061626fce306be41645e/PHASE4.md). These evidence links preserve the documentation as it existed before repository cleanup.

Recovered historical source snapshots are archival artifacts, not reconstructed development commits. Except for the full 0.8.0 snapshot, older source JARs retain production source/resources but not the complete build/test workspace.

Original code is MIT licensed. Third-party files retain their licenses; `risecode-licenses.zip` contains the license texts and attribution. Baritone remains an optional [upstream download](https://github.com/cabaletta/baritone/releases/tag/v1.19.0).
