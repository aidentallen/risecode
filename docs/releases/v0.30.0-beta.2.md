# 0.30.0-beta.2 — KillAura rewrite review build

Minecraft 26.2 · Fabric Loader 0.19.5 · Java 25

This review build replaces the old KillAura and includes the Liquid Glass UI
from beta.1. The pull request is based on `feat/liquid-glass-ui` so installation
preserves the UI already installed in the authorized Fabric 26.2 profile.

- Original combat implementation informed by inspection of a pinned Meteor revision.
- Weapon families, shield handling, click/look conditions and owned hotbar switching.
- Bounded multi-target batches, five priorities, entity IDs, hitbox/wall ranges,
  age/named/tamed/passive filters, friends and team protection.
- Vanilla cooldown or custom tick delays, slot delays, estimated TPS and lag pause.
- Visible Always/OnHit/None rotation timing, GUI/item-use pauses and optional owned
  Baritone navigation pausing. Compatible profile keys remain; MinCPS/MaxCPS are removed.

## Verification

Dependency checksum verification and `check build` passed. The deterministic
combat suite passed 74 assertions. The same production JAR passed native OpenGL,
native Vulkan, Sodium OpenGL, and Sodium/Iris OpenGL runs, each including 39
KillAura assertions. No shader pack was active. A separate run with Baritone 1.19.0
also passed all combat assertions, then failed the post-main shutdown watchdog
(native exit 248); its thread dump showed live Baritone workers. That run is
recorded separately and is not counted as a clean pass.
The native suite includes the existing engine/combat tests and additional KillAura
checks for filters, multi-target packets, cancellation, slot ownership, OnHit
rotation, timing and repeated enable/disable cleanup. Existing combat checks
verify real server-side mob damage and movement-before-attack packet order.

To reproduce a packaged native run:

```sh
python3 scripts/fetch-dependencies.py
GRADLE_USER_HOME="$PWD/.tooling/gradle-home" ./gradlew check build --offline --no-daemon
GRADLE_USER_HOME="$PWD/.tooling/gradle-home" ./gradlew runClientGameTest \
  -PcombatOnly -PclientTestDirectory=build/run/killaura-review \
  -I scripts/panorama-packaged-tests.gradle --offline --no-daemon
```

Use `-PgraphicsBackend=VULKAN` for native Vulkan, `-PrendererStack -PwithoutIris`
for Sodium OpenGL, or `-PrendererStack` for Sodium/Iris OpenGL. Graphical access is
required. These checks do not establish remote multiplayer/anticheat behavior,
a long-session soak, performance gains, or active Baritone task pause/resume
behavior. TPS and lag-boundary tests use a deterministic clock. No rendering
hooks or native terrain/fluid geometry are changed by the combat rewrite.

The build remains opt-in. Installation backs up the previous matching mod outside
`mods/`, preserves configuration and unrelated mods, and requires a Minecraft
restart. A PR and draft prerelease do not merge or replace the public stable release.
