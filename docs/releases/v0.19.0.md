# risecode 0.19.0 — Appearance and block highlights

[All versions](README.md) · [Changelog](../../CHANGELOG.md) · [Project home](../../README.md)

Minecraft 26.2 · Fabric · Java 25

- **Render → Block Overlay:** Smooth Switching defaults on with a 0.15-second transition. Optional Pop Animation grows from the animated center on each new target, defaulting to 0.18 seconds. Both durations support 0–5 seconds; zero is immediate. Reduced Motion disables these animations. The growing highlight remains visible inside the target block, then resumes normal depth testing when settled.
- **Outline Style → Corners:** Edge Gap removes 0–100% from the middle of each edge, defaulting to 60%. Fill, colors, opacity and width remain independent. Actual partial block shapes are retained, and the module suppresses duplicate vanilla outlines while enabled.
- Every module has **Appearance → Use Global Appearance**, enabled by default. Disable it for its card and own HUD. Local palettes, fonts, backgrounds, imported images/sounds, effects and animation settings are retained when inheritance is switched back on. Whole-window settings remain global.
- Local appearance belongs to appearance preferences/profiles. Existing explicit module animation overrides migrate once; new controls replace the old duplicate animation rows.
- Settings sections start collapsed and remember their state across navigation and restarts. Revealing a setting opens its group; collapsing commits focused text and releases hidden controls.
- Themed action buttons use the tabs’ 17-unit height, label scale and label-fitting padding, including supported Minecraft and Sodium menus. Action rows wrap when needed; icon buttons remain compact.
- Tabs and themed buttons remain compressed until mouse-up, including release outside the control. Keyboard actions keep their brief feedback. Focus loss and screen changes cancel held state.
- The client resize mark fades in near the lower-right corner and stays visible while resizing.
- NoFall is always labeled **Blatant** and remains in the Player tab.

Navigation, profiles, terrain, waypoints and unrelated mods are preserved. Restart Minecraft after replacing the JAR.
