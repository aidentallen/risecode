# risecode 0.14.0 — Resources and Ambience

Minecraft 26.2 / Java 25.

Resources replaces Styles with the complete public Vanilla Tweaks resource-pack
picker. Search categories, inspect previews and compatibility notices, select
resources, and arrange top-first priority in Selected. Apply activates the draft;
Cancel or closing discards it. Overlaps warn without silently removing choices.

The complete catalog, individual packs, icons, previews and combined-asset recipes
are cached locally. Once Offline ready, new selections can be built and applied
without contacting Vanilla Tweaks. Downloads can pause, cancel and resume. Refresh
checks for a newer catalog; profiles pin the revision they use.

Render → Ambience restores the procedural sky/water feature as a normal module.
Existing atmosphere settings and bindings migrate. Active Iris shaders retain
sky/water ownership. Old style selections are cleared, and personal Styles files
are archived locally. Minecraft's ordinary resource-pack controls remain available.

Back up configurations before downgrading: schema 5 moves atmosphere values back
into the Ambience module. The automatic pre-resources backups retain the originals.
Restart Minecraft after replacing the JAR.

Verification: 711 core assertions; 37 native Iris/OpenGL and 35 native Sodium
Vulkan assertions with EMF/ETF. The full 641-resource cache rebuilt offline with
zero provider requests, including 115 combination recipes and 599 priority
variants. Eight mixed selections matched official generated archives. Native
checks cover draft input, ordering, font/audio/model reloads, profiles, rollback,
Ambience bindings and Iris handoff. These checks do not certify every resource
against every optional renderer.
