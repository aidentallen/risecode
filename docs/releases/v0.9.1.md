# risecode 0.9.1 — NoRender environment fog controls

[All versions](README.md) · [Changelog](../../CHANGELOG.md) · [Project home](../../README.md)

Archived release restored from retained artifacts. Original publication dates and Git history were not retained.

## Changes

- Added the disabled-by-default NoRender module under Render.
- Added All Fog and independent Overworld, Nether, End, other-dimension, water, lava, powder-snow, blindness, and darkness controls.
- Persisted controls through module configs/profiles and restored native fog on disable; Iris retains its shader-pack fog path.
- Preserves the original installed release JAR rather than the later build-folder rebuild of the same version.

## Requirements

Minecraft 26.2, Java 25, Fabric Loader, and Fabric API. Install the mod JAR; sources are separate.

## Provenance

Notes were reconstructed from the retained binary/source artifacts and [UPGRADE.md](https://github.com/aidentallen/risecode/blob/44cc1f286ac601a59e65061626fce306be41645e/UPGRADE.md). These evidence links preserve the documentation as it existed before repository cleanup.

Recovered historical source snapshots are archival artifacts, not reconstructed development commits. Except for the full 0.8.0 snapshot, older source JARs retain production source/resources but not the complete build/test workspace.

Original code is MIT licensed. Third-party files retain their licenses; `risecode-licenses.zip` contains the license texts and attribution. Baritone remains an optional [upstream download](https://github.com/cabaletta/baritone/releases/tag/v1.19.0).
