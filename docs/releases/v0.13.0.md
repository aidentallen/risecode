# Agent 0.13.0 — Experimental controllers

Historical release: the Agent feature and its guides were removed in [0.13.1](v0.13.1.md).

This extends the verified Agent release with reviewed server-synchronized container
transfers, unlocked crafting batches, equipment/loadout preparation and a bounded
safe-food survival routine. Local prediction never proves a world action; server
confirmation and final item/hunger/equipment readback do. Stop/session/manual
intervention prevents further clicks/use, without replaying partially applied work.

Iris 1.11.4 gains actual installed pack selection and loaded option choices, saved
properties checks, renderer readback and targeted Undo. Sodium 0.9.2 and Sodium
Extra 0.9.4 expose only registered public fields; native edits invalidate stale Undo.
Other configurations remain preserved. Iris' own graphics reload can hitch.

Recognized inspection commands use zero model tokens. Remote schemas are selected
by objective, shader metadata is capped, waiting inventory ticks avoid repeated
serialization, and idle controllers perform no scans or provider requests.

See completion evidence, the guide,
architecture and performance.
These are bounded experimental integrations, not general human-level autonomy or
safe-path/survival guarantees. The pinned Baritone worker-shutdown limitation remains
explicitly documented. Credentials remain session/environment only.

Installation replaces exactly Fabric ID `riserecode`, with a recovery backup,
checksum and unchanged unrelated mods/configurations. Minecraft must restart.
