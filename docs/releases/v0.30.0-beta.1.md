# 0.30.0-beta.1 — Liquid Glass interface review build

Minecraft 26.2 · Fabric Loader 0.19.5 · Java 25

This is an unmerged feature-branch build prepared for pull request review.

- Shared glass material with curved-edge refraction, local luminosity adaptation,
  directional highlights and existing pooled backdrop blur.
- Floating sidebar, animated selection pill, grouped header, capsule switches,
  pill slider handles and focused text fields.
- Matching menu controls, popups, tooltips and HUD surfaces.
- Independent refraction/highlight settings and Classic fallback; full Liquid
  Glass palette/font preset with Undo. Existing saved settings remain intact.

[Material guide and references](../liquid-glass.md)

- The production JAR passed disposable-client suites on vanilla OpenGL, native
  Vulkan, Sodium OpenGL, and Sodium/Iris OpenGL. The Iris suite additionally enabled

- Preset/Undo and Classic-material behavior pass the deterministic theme checks.

[Machine-readable artifact verification](v0.30.0-beta.1-verification.json)

Reproduce a packaged native run with:

```sh
GRADLE_USER_HOME="$PWD/.tooling/gradle-home" ./gradlew runClientGameTest \
  -PliquidGlassOnly -PclientTestDirectory=build/run/liquid-glass-review \
  -I scripts/panorama-packaged-tests.gradle --offline --no-daemon
```

Use a separate disposable test directory for each renderer. Add
`-PgraphicsBackend=VULKAN` for native Vulkan, `-PrendererStack -PwithoutIris` for
Sodium, or `-PrendererStack -PwithShaderPack` for Sodium/Iris with the locally
available Complementary Unbound pack. Real client runs require graphics.

This build does not claim an FPS improvement, pixel-identical Apple rendering,
arbitrary shader-pack compatibility or a long-session soak result. Popup/control
surfaces do not refract other GUI layers. No terrain or fluid geometry is changed.

Installation replaces only the matching Risecode JAR after backing it up outside
`mods/`. Minecraft must restart to load this version. Main remains unchanged until
the pull request is merged.
