# 0.11.1 — Restore AI conversation context

Opt-in history now restores conversation context for the model after restarting
Minecraft, alongside the visible chat. Up to eight completed requests and 65,536
context characters are retained. Recorded tool outcomes remain separate from
unverified assistant prose and describe past state; current state must be inspected
again before editing.

Stored context contains plain messages and redacted receipts, never executable
tool calls, raw arguments, credentials or pending approvals. Loading history makes
no provider request and resumes no action. Existing version-one chat migrates to
context without inventing missing tool receipts. Clear removes visible and model
history; disabling persistence removes both archives from disk while keeping the
independent action audit and Undo records.

Minecraft 26.2 / Java 25, Styles and ordinary profiles remain compatible. Live
provider testing and performance benchmarks remain pending; this patch does not
add world actions or later integration milestones.
