# risecode 0.15.0 — Navigation, typography and world utilities

Minecraft 26.2 / Java 25. The project retains its MIT license.

The gear button opens Settings with Friends, Profiles, Waypoints and Map settings.
Friends, profiles, commands and saved navigation destinations remain available.
Appearance and Resources stay in the sidebar. All Resources views use the shared
scrolling animation channel, clamp both position and destination after changes,
and use displayed positions for clicks and drag ordering.

Minecraftia remains an optional local TTF. It now uses visible capital-height
metrics rather than its unusually large em box. Widths, wrapping and selection
share advances and kerning with drawing. Integer physical scales use crisp
sampling; fractional scales use filtered coverage. Font Scale and other faces
remain available, with native Unicode fallback.

Eight new modules start disabled and use ordinary settings, Hold/Toggle bindings
and profile persistence:

- Nametags: names, health, distance, ping, equipment, friend colors, range, scale
  and through-terrain text; replaces the corresponding vanilla player label.
- Trajectories: held bow/crossbow/trident and throwable centerlines, plus optional
  loaded-projectile paths, native physics order, fluid drag and impact markers.
- AutoTool: native mining/drop rules, hotbar selection, low-durability filtering,
  previous-slot restoration and opt-in synchronized Inventory Tools swaps.
- FastBreak: inter-block delay removal and adjustable native progress. Defaults
  to no delay and a 1× multiplier; vanilla prediction and correction remain active.
- BetterChat: timestamps, repeated-message counts, mention highlighting, copy
  actions and bounded history. Original signed entries, links and hover actions
  are retained; repeated signed entries are annotated rather than discarded.
- BetterTab: numeric latency, friend marking, configurable rows and optional
  name/ping/friend sorting. Vanilla sorting is the default; server names, teams,
  headers, footers and score content use the native overlay.
- Waypoints: in-world destination names, distance, colors, tracking and beams.
- Minimap: a textured graphical element placed and scaled in the HUD editor,
  with zoom, rotation, compass and waypoint controls.

M opens the world map and B adds a waypoint at the player. Both are rebindable in
Minecraft Controls. The world map supports smooth pan, cursor-centered zoom,
coordinates, recentering, dimension selection and the shared waypoint manager.
Destinations have names, coordinates, dimensions, groups, colors and independent
visibility/tracking. The latest death marker per dimension persists until reached
or removed. Map and manager access does not require either overlay module.

Recording defaults on while connected and can be disabled in Map settings.
Surface snapshots contain only terrain received by the client. Top-face texture
colors combine with biome tint, water depth and height shading. Snapshots retain
palette, height and tint information for resource reloads. Explored terrain and
waypoints persist separately from profiles, isolated by world/server and dimension.
Cave layers are outside this release.

Recording targets a 1.5 ms client-tick budget with at most 32 columns per tick.
Immutable snapshots, overview derivation and disk writes use one bounded worker.
There are at most 16 pending tile jobs, 512 CPU tiles, 512 GPU textures and four
texture uploads per frame. World changes invalidate pending display results;
old-world writes retain their captured paths. Persisted density overviews allow
wide zoom levels without retaining all exact tiles in memory. Rendering uses
Minecraft's backend-neutral APIs.

Trajectory previews exclude random launch spread and future entity movement.
The displayed collision can change when a server moves an entity, changes a block
or corrects a projectile. Returning/homing behavior after an impact is not a
prediction of future targets. A server may reject accelerated mining or a swap;
normal synchronized interactions and guarded restoration remain in use.

The pure page-layout and density helpers are adapted from Simple Map revision
`564eb2ec950d5db80b4534c9d0d794ef050ee838`, Copyright (c) 2026 Velorise, MIT.
The pinned license and adaptation details are retained in the JAR and
[third-party notices](../../THIRD_PARTY_NOTICES.md).

Restart Minecraft after replacing the release JAR. Back up
`config/riserecode/maps/` when transferring worlds or instances.
