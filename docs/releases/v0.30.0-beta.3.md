# 0.30.0-beta.3 — Tactile click sounds

Minecraft 26.2 · Fabric Loader 0.19.5 · Java 25

Eight original synthesized sounds are available in **Client settings → Sounds →
Click Sound**. Use **Preview Sound** to compare them:

- **Thock**: low, layered keyboard impact.
- **Creamy**: rounded keyboard tap with a softer attack.
- **Marble**: compact, resonant hard-surface tap.
- **Bubble**: descending bubble pop.
- **Snap**: short, crisp transient.
- **Ceramic**: bright, hollow impact.
- **Rubber**: springy, rounded pop.
- **Chime**: light, brief ringing tone.

The original eight assets and existing selection are preserved. All choices use
the shared activation path, Click Volume, Click Pitch, and master Sounds switch.
Local OGG imports and muted/vanilla choices remain available. No downloaded audio
or third-party samples are used; the generator and bundled sounds use the project
MIT license. Run `python3 scripts/generate-ui-sounds.py --new-only` to regenerate
only the new sounds. This build includes the pending Liquid Glass and KillAura
branches; its source change is stacked on the KillAura branch for review.

## Verification

Dependency checksum verification and `check build` passed, including 78 assertions
in the sound/settings suite. Every bundled choice is checked for a registered
sound event, an OGG asset, and settings round-trip compatibility. All eight new
assets were decoded from the production JAR: mono 44.1 kHz, approximately
82–237 ms, decoded peaks below 0.64 full scale.

The focused packaged-client OpenGL run exercises every bundled sound and native
button activation feedback (19 assertions). It uses an isolated test directory;
personal settings are not loaded. These checks establish resource resolution and
sound-engine playback acceptance; they do not measure subjective listening quality.
The broader legacy UI run reached sound playback but failed later on its outdated
“original ten tabs restored” navigation assertion. Navigation is unchanged here.

```sh
python3 scripts/fetch-dependencies.py
GRADLE_USER_HOME="$PWD/.tooling/gradle-home" ./gradlew check build --offline --no-daemon
GRADLE_USER_HOME="$PWD/.tooling/gradle-home" ./gradlew runClientGameTest \
  -PuiSoundsOnly -PclientTestDirectory=build/run/click-sounds-final \
  -I scripts/panorama-packaged-tests.gradle --offline --no-daemon
```

Installation backs up the previous matching mod outside `mods/`, checks the
installed JAR checksum and exactly one `riserecode` mod, and verifies unrelated
mod files remain identical. Restart Minecraft to load the update.
