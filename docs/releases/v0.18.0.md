# risecode 0.18.0 — Cosmetics and legacy cape physics

[All versions](README.md) · [Changelog](../../CHANGELOG.md) · [Project home](../../README.md)

For Minecraft 26.2, Fabric and Java 25.

- Add **Utilities → Cosmetics** with 26 offline items, optional downloadable companions, PNG cape imports and a live character preview. Apply or cancel outfit edits; outfits belong to the selected profile and start unequipped. Cosmetics are visible locally.
- Add capes, animated wings, headwear, tails, companions, trails, auras and particles with category-specific appearance and motion controls.
- Add optional **Render → Cape Physics** for legacy cape motion with adjustable strength.
- Clamp expanded glow clipping rectangles to the render area to prevent Minecraft 26.2 scissor validation crashes.
- Keep profile save/load controls in Profiles and repair header, gear and HUD button alignment.
- Preserve the restored module tabs, Utilities menu, scrolling Appearance page and Subtle/Accent Button Style option.

Existing configuration, profiles, explored terrain and waypoints are preserved.
Restart Minecraft after replacing the JAR.
