# risecode 0.12.0 — Agent

[All versions](README.md) · [Changelog](../../CHANGELOG.md) · [Project home](../../README.md)

Historical release: the Agent feature and its guides were removed in [0.13.1](v0.13.1.md).

Minecraft 26.2 / Java 25; preserves existing Styles and name-based profiles.

## Behavior

The native AI tab is now **Agent**. Recognized module/settings/read/Undo commands
run locally through the trusted executor and consume zero model tokens. Remote
requests select relevant schemas and retain bounded context; unset budgets are
smaller, repeated tool failures stop, and OpenRouter supports input/output price
ceilings with no upstream fallback.

New tools provide opt-in bounded game context, real vanilla option callbacks,
Iris configured/effective state and enable toggles, named profile preparation,
binding edits, reviewed preferences and documentation. Targeted Undo checks later
human edits and preserves unrelated state. Vanilla option saving runs off-thread
and preserves FullBright's original gamma.

Approved Baritone tasks navigate, mine, follow, explore, or gather additional items
and return to the saved start. Completion comes from deterministic observations,
not task launch or model prose. Resource leases, conflict previews, manual pause,
watchdogs, time/safety budgets and interrupted checkpoints are enforced. F12 works
while composing and never starts an automatic return or restarts automation.

On-demand median/p95 frame metrics support reviewed one-candidate experiments.
Two baseline and two candidate windows must remain comparable. Below-threshold,
noisy or regressive results restore the candidate; cancellation during persistence
uses a verified recovery checkpoint and preserves human edits.

## Verification and limits

See the completion report and
performance evidence for final counts and measured scope.
Executable checks and native fixtures cover actual setting/option/binding/profile
readback, Undo, privacy, cancellation and measured experiments. Separately budgeted
OpenRouter tests verify real native module control; offline routes make zero calls.

Iris 1.11.4's public setter synchronously saves/reloads and cannot prove persistence;
explicit toggles can hitch. Baritone API Fabric 1.19.0 functionally completes the
controlled tasks but retains cached-world workers at shutdown; its public API has
no worker-close operation. General survival, crafting/containers, arbitrary mod or
shader-pack tuning, model-specific reasoning controls and OS keyring storage remain
unexposed. No provider intelligence or safe-path guarantee is claimed.

The release requires a Minecraft restart. Installation replaces only Fabric ID
`riserecode`, with backup and checksum verification; existing configurations and
other mods are preserved.
