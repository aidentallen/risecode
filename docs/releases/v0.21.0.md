# 0.21.0 — Placement motion and shader lighting

Open **Render → BlockAnimations** for Swing (default), Pop, Slide or Custom placement
motion. Timing, easing, strength, range, active limit, scale, translation, rotation
and pivot are configurable. Editing a transform selects Custom. Your placements
are enabled by default; Other Players is opt-in and requires a nearby player's
held block, swing, aim and a matching server block update. Uncertain changes stay
static. Reduced Motion disables placement motion.

**Outline Behavior** selects Follow Animation (default), Hide Until Settled or
Fixed Position. Follow Animation transforms the actual outline corners with the
model. BlockOverlay's entrance pop plays when acquiring a block after looking
away; direct target changes only switch. Enable **Pop On Switch** for the old
per-target pop behavior.

Moving models use Minecraft's world rendering, neighbor lighting and ambient
occlusion. Iris receives shader material identity and moving shadow submissions.
The block returns to terrain after the rebuilt mesh reaches the GPU. Animation
limits and range avoid unnecessary work; idle frames request no terrain rebuilds.

Fluids, double blocks, beds and double chests stay static. Light-emitting blocks
also stay static with shaders because moving only the visible mesh would separate
it from the shader's world lighting. Shader pipelines that replace all native
world drawing stay static. A Good Place is neither bundled nor copied; this is a
native implementation with no additional runtime dependency.

**FullBright → Mode → Shader Night Vision** provides adjustable night vision to
Iris packs that use its `nightVision` uniform. The mode preserves stronger real
night vision and does not add potion effects, place client light blocks, change
gamma or edit shader-pack settings. Brightness depends on the pack; packs that
ignore that uniform will not respond. Lightmap remains the default FullBright mode.

**Player → Clutch** replaces the NoFall display name and uses the Ghost badge.
Existing modes and behavior remain available. Old NoFall profiles, keybinds,
appearance identity and command lookup migrate to Clutch; canonical Clutch data
wins if both names exist.

Validated with Minecraft 26.2 / Java 25 using vanilla OpenGL, Sodium 0.9.2 /
Iris 1.11.4 with Complementary Unbound r5.9.3 and BSL v10.1.8, and Sodium Vulkan.
Checks cover real item placement, acknowledged terrain uploads, rotated outlines,
lighting handoff, shader shadow submissions, resource reload, remote attribution,
module toggles, reduced motion and disconnect cleanup. Outline pixel checks cover
width, opacity, corner gaps, fill and see-through edges. Shader night vision is
checked against rendered cave pixels at zero, half and full strength, then disabled
to verify restoration.
