# risecode 0.17.0

Minecraft **26.2**, Fabric, Java **25**.

- Six primary pages: Search, Gameplay, Visuals, HUD, Appearance, Resources. Friends, Profiles and map management remain in the Settings hub. Module identifiers, profiles and map data are preserved.
- Appearance has six focused sections and cross-section setting search. HUD styling is available through HUD → Style; map styling remains reachable from Map Settings.
- Shared tab-style buttons, hover/press feedback, unclipped glow, sharper title lettering, and five additional original click sounds: Tick, Tap, Mechanical, Wood, Glass.
- Right Shift closes focused search and value editors. Baritone destinations use exact integer boxes with Tab navigation, Enter commit and Escape cancellation.
- Wider global, window and module animation ranges: up to 10× speed/strength and 10-second durations. Reduced Motion remains available.
- Each menu/settings screen has a corner gear with theme/background inheritance, per-page customization and reset. Disabling a page's theme retains the recovery gear. Theme profiles include page overrides.
- Animated gradient, aurora and starfield backgrounds, image pan/zoom, and Minecraft-style or smooth rain, snow, dust and abstract particles. Existing imagery and particle defaults are preserved.
- GUI blur captures the underlying world in-world and uses Dual Filtering. The old sparse Gaussian filter was removed after its measured advantage did not meet the agreed retention threshold (5% and 0.2 ms median frame time). This is a quality change, not an FPS guarantee.
- Module cards identify Client, Ghost or Blatant behavior, including mode-dependent labels. Ghost means subtle automation; it is not a promise about server rules or detection.
- NoFall now provides Packet, Auto, Water, Ladder, Powder Snow, Cobweb and Slime modes. Old local-only VANILLA selections migrate to Auto. Clutches use hotbar/offhand items, ordinary interactions and visible rotation, and restore owned controls after confirmation/cancellation. Packet mode preserves movement fields while changing the ground flag.

Clutches require a reachable placement and suitable item. Ladder mode needs a nearby support wall; water respects evaporation zones; slime is skipped while sneaking. Powder snow still has its normal freezing behavior. Server plugins can change fall/placement behavior. Boats, vines and hay/honey mitigation are outside this release.

Verification evidence, screenshots and the blur comparison are stored locally under `build/verification/0.17.0/`.
