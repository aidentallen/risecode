# 0.11.0 — Native AI configuration assistant

Adds an AI tab to the existing ClickGUI with hosted/local Chat Completions
connections, streaming text, masked session credentials, native tool calls,
concrete approval cards, verified module changes and targeted Undo.

The four tools discover registered modules, inspect their supported setting
metadata, apply a validated module patch and undo a recorded change. Explicit
visual changes can apply directly; gameplay/unknown effects and inferred edits
require review. F12 and exact STOP messages stop requests and supported gameplay
controllers locally. Credentials never enter client profiles or AI records.

Configure the API base URL, model ID and optional session key in AI → Settings.
Enter sends; Shift+Enter adds a line; Escape retains the draft. History persistence
starts off. The previous Styles work and name-based profiles remain compatible.

This is the first configuration slice. World actions, Baritone task orchestration,
Responses, arbitrary mod settings and FPS optimization are not implemented.
Live hosted-provider testing requires a user-configured endpoint/credential;
correctness is verified with scripted providers and HTTP fixtures.
