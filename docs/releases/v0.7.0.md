# risecode 0.7.0 — Expanded HUD, camera, and visual modules

Archived release restored from retained artifacts. Original publication dates and Git history were not retained.

## Changes

- Added concurrent frame animations, seven editable HUD elements, per-profile HUD layouts, and animated gradients.
- Added FreeCam, FreeLook, WeatherChanger, ItemPhysics, EnchantEffect, and BlockOverlay.
- Added the full lightmap FullBright mode with native restoration and retained a configurable gamma alternative.

## Requirements

Minecraft 26.2, Java 25, Fabric Loader, and Fabric API. Install the mod JAR; sources are separate.

## Provenance

Notes were reconstructed from the retained binary/source artifacts and [PHASE8.md](https://github.com/aidentallen/risecode/blob/main/PHASE8.md). The documentation on main also contains later updates.

Historical tags contain recovered source snapshots, not reconstructed development commits. Except for the full 0.8.0 snapshot, older source JARs retain production source/resources but not the complete build/test workspace.

Original code is MIT licensed. Third-party files retain their licenses; `risecode-licenses.zip` contains the license texts and attribution. Baritone remains an optional [upstream download](https://github.com/cabaletta/baritone/releases/tag/v1.19.0).
