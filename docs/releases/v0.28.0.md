# 0.28.0 — SeedCracker

Minecraft 26.2 · Fabric Loader 0.19.5 · Java 25

Built-in SeedCrackerX 2.16.1 under Risecode's namespace. Enable **World → SeedCracker**
to collect; **Start** runs one immutable snapshot. New observations, login, Restore
and toggles never start an attempt automatically. Stop cancels workers/network work
while collection continues. Disabling releases the active session and outlines.

Includes modern finder switches, regular/lifting bits and phase/candidate/result
status, Off/Visible/Through Walls outlines, scoped atomic archives, explicit
Restore and local `.seedcracker` commands. Optional lookup and authenticated manual
submission both default off. Copy Seed requires one hash-verified world seed.

## Release assets and installation

The release includes the production JAR, standard sources JAR, complete buildable
source ZIP, license bundle and `SHA256SUMS`. Source ZIP corresponds to the published
Git tree. SeedCrackerX itself is only a checksum-pinned build-time extraction source;
it is not installed as a second mod. Do not add standalone SeedCrackerX alongside it.

The verified JAR replaces only mod ID `riserecode` in the Modrinth **Fabric 26.2**
instance, after backing up the old JAR outside `mods/`. Configuration and unrelated
mods are preserved. Restart Minecraft to load 0.28.0; the installer does not stop it.
Local installation receipt: `.tooling/seedcracker/install-receipt.json`.

## Verification boundaries

No live multiplayer, real database submission/account-authentication, long-session,
FPS, GPU-time or isolated allocation claim. Automated database checks use a local
mock service. Finder CPU diagnostics are cumulative client-thread scan time, not
GPU or FPS measurements. Individual scans can be expensive; queues and observations
are bounded and all collection is opt-in. Arbitrary shader packs, custom worldgen,
server obfuscation and player-built structure lookalikes remain outside this fixture.
Remote generator settings are not fully exposed to clients: choose a distinct
Generation Profile for changed server worlds/datapacks/salts. Flat/debug worlds,
custom dimension IDs and older-server translation are unsupported.
