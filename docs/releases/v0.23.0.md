# risecode 0.23.0 — Settings panels and complex block contours

[All versions](README.md) · [Changelog](../../CHANGELOG.md) · [Project home](../../README.md)

- The small footer popup uses one continuous themed background, retaining its opening animation and transformed input handling.
- Client Sounds, Discord Activity and GUI Scale open in the existing client window. Quick toggles, sound imports and previews, connection status, settings persistence and page customization remain available.
- Appearance cards animate their entire background, border, text and controls together. Module cards and Appearance cards share the existing Button Feedback compression, strength, rebound and timing settings. Reduced Motion and zero strength disable the response.
- BlockOverlay uses merged Minecraft selection-shape edges and exposed union faces. Stepped and connected shapes retain their contours without internal box seams, duplicate corner segments or overlapping internal fill faces.
- Interrupted transitions advance before retargeting, including changes between different block topologies and between blocks and entities. Placement following and shader overlay compositing remain supported.
- Every registered module has an explicit presentation audit. HUD panels, map backgrounds, text, bars, labels, world paints and motion preferences expose their actual controls. Inactive modes hide irrelevant controls, and saved legacy overrides remain intact.

Minecraft 26.2 and Java 25 remain required. Generated verification evidence and renderer-specific screenshots are stored locally under `build/verification/0.23.0/`.

## Verification

The full `check build` suite and 24 new core assertions passed. Packaged native checks
passed on vanilla OpenGL, Sodium/Iris with Complementary Unbound 5.9.3 and BSL 10.1.8,
and Sodium with Vulkan. Each configuration swept 32,366 registered block states and
audited all 39 modules. The final matrix captured 219 screenshots, with representative
UI, complex contours and shader fills inspected visually. Existing hitbox, block-outline
pixel and placement regressions also passed where selected by the matrix. The optional
legacy placement performance benchmark was excluded; this release makes no new FPS claim.
