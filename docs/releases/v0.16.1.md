# risecode 0.16.1 — UI motion repairs

[All versions](README.md) · [Changelog](../../CHANGELOG.md) · [Project home](../../README.md)

Minecraft 26.2 / Java 25 / MIT. Existing profiles, appearance preferences, terrain,
waypoints and HUD placement remain compatible.

- Restore sidebar hover fades, subtle label movement, the moving selection
  highlight and short page-switch slide/fade. Utilities retain inline expansion,
  scrolling and keyboard navigation.
- Keep menu backdrops full-screen and stationary while foreground content scales
  and fades together. Suppress redundant vanilla background/dimming layers and
  preserve transformed input and clipping. Tooltips retain their own motion.
- Replace the timed press pulse with a per-button damped spring. Repeated presses
  preserve position and velocity, with adjustable compression, rebound, strength
  and timing. Cover client buttons, native controls and supported Sodium buttons;
  actions and sounds dispatch immediately once. Reduced Motion resets feedback.
- Compact Appearance's theme toolbar. Move imports, preview, font reload, layout
  reset and preset actions beside their settings; wrap controls at smaller sizes
  and give galleries complete rows.

Validation includes deterministic spring checks and native transition frame
sequences, mouse/keyboard dispatch, sidebar navigation, small-window layout,
Reduced Motion, background opacity and menu brightness checks.

Verification: `895` core assertions and `166` native assertions passed.
The final UI sequence passed on vanilla OpenGL, the installed Sodium/Iris OpenGL
stack and Sodium Vulkan. Background edge pixels matched across early, middle and
settled entrance frames on all three renderers.
