# risecode 0.10.0 — Styles

[All versions](README.md) · [Changelog](../../CHANGELOG.md) · [Project home](../../README.md)

For Minecraft 26.2 and Java 25.

The Styles sidebar mixes local imports and cloud pack categories, with previews,
search, and a single Apply action. Existing client profiles now retain applied
style selections and built-in Sky/Water controls. The former Ambience module is
removed from the module registry; its saved controls and binding migrate.

Native item/block models preserve resource dependencies. Imported entity/model
targets support separate EMF/ETF installations, including model parts, animations,
random variants and emissive textures. Imported cube skies have a native renderer;
Iris shader packs keep control of sky and water while enabled.

Resource downloads are hash checked and cached locally. A failed Styles reload
restores the preceding selection rather than clearing ordinary resource packs.
The release contains no cloud artwork or bundled EMF/ETF code.

See [the archived upgrade guide](https://github.com/aidentallen/risecode/blob/44cc1f286ac601a59e65061626fce306be41645e/UPGRADE.md) for import, profile, migration, and compatibility
details. Additional Bauloo extras, cosmetics, and public preset sharing are not
part of this version.
