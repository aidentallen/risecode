# 0.29.0 — Base Finder

Minecraft 26.2 · Fabric Loader 0.19.5 · Java 25

Enable **Render → BaseFinder** for integrated suspicious chunk, stash, growth and
amethyst clues. Includes Classic, ANBS+, weighted Activity Clues, packet light
analysis, geode flood fill, local structure filters, block/chunk outlines and
centroid tracers. Frosted cards show clue counts and live coordinates/distance;
**P** pins the first card and **Delete** dismisses cards. Disabled by default.

imported. Existing bundled libraries, licenses and attribution are retained.

Installation preserves the previous matching JAR outside `mods/`, configurations,
and unrelated mods. Minecraft must restart to load this version.
