# SeedCracker license provenance

SeedCrackerX: `19MisterX98/SeedcrackerX`, commit
`b72a829f768967fa737a4f1f63b32e37b9619152`, root `LICENSE`.

SeedFinding: root `LICENSE` or `LICENSE.md` from `SeedFinding/mc_<name>_java`
at each revision named in the dependency JAR filename/manifest. These are
MIT notices with their original copyright statements.

LattiCG 1.07: `mjtb49/LattiCG`, MIT notice from the repository's root `LICENSE`.
The 1.07 binary is pinned by the official SeedCrackerX release archive and its
extracted checksum. The repository no longer exposes a 1.07 tag; its current
MIT text retains the original 2020 mjtb49 copyright.

All nine libraries are extracted from the official SeedCrackerX 2.16.1 release
(SHA-256 `657a6b998d7dc4e5e2c6b7ebd5e2268cfb79c1b6bc4e5976294c3c5b3fcdf89e`).
That upstream mod itself is a build-time extraction source and is never included
as a second mod/initializer in Risecode.
